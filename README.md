# Mabroukui

موقع أحمد مبروك على `https://v2.mabroukui.com/`: بورتفوليو داكن سينمائي بيتبني لايف قدام الزائر، هيرو بكلمة PORTFOLIO عملاقة خلف البورتريه، أعمال مختارة، الشغل والأثر، مقارنة Wireframe ↔ Final UI، خط زمني للخبرات، وصفحة تواصل.

- البناء اللايف: فريق من الماوسات (agents) بيبني كل سكشن أول ما يظهر في السكرول، يرسم الفريمات وينزّل الصور ويكتب النصوص، وأي عنصر متكرر بيتعمل مرة واحدة وبعدين يتنسخ ويتعدّل. فيه زرار تخطي، واللي مفعّل تقليل الحركة بيشوف الموقع ثابت.
- ملف واحد `index.html` (فيه الـ CSS والـ JS) + مجلد `assets/`.
- عربي (RTL) افتراضيًا مع زر English، واللغة بتتحفظ في المتصفح.
- الخطوط: Ping محليًا في `assets/fonts`، وAnton / Alexandria / Aref Ruqaa / Caveat Brush / DM Sans من Google Fonts.
- صورة معاينة الرابط: `assets/share-cover-en.jpg`.

## التشغيل محليًا

دبل كليك على `index.html`، أو من داخل المجلد:

```sh
python3 -m http.server 8000
```

وافتح `http://localhost:8000`.

## النشر

الموقع منشور على GitHub Pages من فرع `main`، والدومين `v2.mabroukui.com` مربوط عن طريق ملف `CNAME`. أي push على `main` بيتنشر لوحده.
